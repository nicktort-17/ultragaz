# pipeline — рабочие файлы конвейера новых 3D-моделей

Здесь лежит всё промежуточное: референсы из ChatGPT, 4 вида для Tripo, сырые модели из Tripo, заметки.
**Ни игра (`index.html`), ни скрипты (`dev/`, `blender/`) на эту папку не ссылаются** — её можно удалить или
перенести, и ничего не сломается. Готовая модель после чистки в Blender копируется в `models/` (и `models_js.py`).

Структура — по папке на модель:

```
pipeline/<имя-модели>/
  notes.md        задача, промпты, решения, ссылка на модель в Tripo
  ref/            референс в полоборота (варианты 01.png, 02.png …), одобренный — approved.png
  views/          front.png, right.png, left.png, back.png
  tripo/          скачанная из Tripo модель (*.glb и т.п.; в git не попадает — см. .gitignore)
```

Картинки (`ref/`, `views/`) и `notes.md` хранятся в git, сырые модели — нет (большие; итог всё равно в `models/`).
