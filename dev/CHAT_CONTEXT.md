# Контекст переписки (перенос из чата claude.ai в Claude Code)

Этот файл — выжимка долгого чата, в котором игра делалась до переезда в Claude Code. Прочитай его вместе с `CLAUDE.md` и `dev/parts/NOTES.md` (там подробный технический журнал по датам).

## Пользователь и как с ним работать
- Пишет по-русски, отвечать по-русски. Обычно присылает скриншоты со стрелками/кружками и короткое ТЗ.
- Любит, когда результат показывают картинками (скриншоты до/после, листы с ракурсами).
- Новые 3D-модели — сначала показать на согласование.
- Скачивание файлов на его компьютер — только с явного разрешения на каждый раз.
- Проект некоммерческий, можно использовать свободные ассеты, но следить за производительностью.
- Blender стоит на его основном компьютере.
- Хостинг: GitHub `nicktort-17/ultragaz`, GitHub Pages https://nicktort-17.github.io/ultragaz/. Раньше параллельно публиковался артефакт claude.ai «ULTRAGAS» (slug f7b93ac4-6f05-4a7b-a04f-6fb1a010d93e) — из Claude Code его обновлять не нужно, основной канал теперь GitHub Pages.

## Жёсткие ограничения по контенту
- Никаких логотипов Coca-Cola/Pepsi и маскота Pepsi. Бренды вымышленные.
- Пепсштейн — строго сатира на корпорацию-монополиста газировки (без намёков на реальных людей).
- Никаких фото реальных людей. Все персонажи взрослые, без откровенного контента.

## Что за игра
ULTRAKILL-подобный шутер про колу: быстрое движение, 4 «газированные» пушки (Шипучка с крышечками-монетками, Шейкер, Ментос-пушка, Газьява), кулак-парирование, шкала стиля, сюжет из уровней по 3 зала, аркада соло/кооп/PvP, онлайн через публичный MQTT.
- L1 «Линия розлива» (босс — Генеральный директор), L2 «Сиропные цистерны» (Карамельная Царица), L3 «Пивное море» на яхте (босс Альтушка 10/10 на танке, затем на ракете), L4 «Остров Пепсштейна» (пляж → джунгли → вилла → храм; босс Пепсштейн в 3 фазах).

## Последние сделанные задачи (в хронологическом порядке)
1. **Босс Пепсштейн:** переработаны волосы, рукава, балахон, трубки/механика (blender/pep_host.py). Во 2-й фазе старик того же размера, что в 1-й, сидит в кабине в воротнике большого робота-костюма, голова смотрит прямо (pep_ph2.py, `P2_seat`). Способность «Франшиза» призывает Кетональщиков (автоматы на ногах), в ярости — 3.
2. **Полировка карты L4:** коллизия камней по реальной форме (растр-высоты `L4.rockF` + `TERR.h` = max(рельеф, камень), невидимые прокси для пуль); все 5 дверей острова — `isleGate()` с рамами, табличками, световыми полосами у проёма; режимы дверей 'slide'/'sink'; переделаны вышка спасателя, тики-бар, соломенные крыши, фонтан у храма (вода, струи, завеса, коллизия кольцом), перила мостика, подпорная стена храма, окна виллы, стойки бара у бассейна, полосатые ткани на пляже.
3. **Метр стиля «бутылка»** (по концепту пользователя): бутылка колы наполняется с рангом, пузырьки, пена с A, тряска на SS, взрыв бутылки на SSS; крупная буква ранга с цветами D голубой / C бирюза / B салатовый / A жёлтый / S оранжевый / SS-SSS красный; 5 делений = прогресс до следующего ранга; название ранга — наклонная плашка цвета ранга (Oswald) с бликом. Код — `dev/parts/patch_style.py`. Ранг F сознательно не добавлен (шкала начинается с D) — можно добавить, если попросит.
4. **Циферблат крышечек** на белой задней крышке Шипучки: 4 деления по краю, 4 крышечки, заряжающаяся наливается газировкой, число в центре, вспышка и «дзынь» при восстановлении. `dev/parts/patch_capdial.py`.
5. **Синие враги на L4:** на острове все обычные враги (автомат, банка, дрон, голем, кето) перекрашены из красного в синий, +40% HP, +12% скорости, и у каждого новая атака: автомат — веер из 3 зарядов; банка — шипит и делает рывок со взрывом; дрон — очередь из 3 зарядов; голем — расходящаяся ледяная волна (перепрыгивать); кето — рывок-пинок. `dev/parts/patch_blue.py`.
   - Известное ограничение: в коопе подготовка голема/банки и сама ледяная волна видны только хосту (не передаются по сети). Хороший кандидат на доработку.
