# УЛЬТРАГАЗ

Браузерный шутер в духе ULTRAKILL на тему колы: быстрое движение, четыре газированные пушки, парирование, шкала стиля и онлайн.

**Играть:** откройте `index.html` или страницу GitHub Pages этого репозитория.

## Режимы
- **Соло · PvE** — бесконечные волны автоматов, мятных дронов и сахарных големов.
- **Кооп · PvE** — те же волны вместе с друзьями, без огня по своим.
- **PvP · арена** — все против всех, фраги и возрождение.

Чтобы играть вместе, все открывают одну и ту же ссылку, вводят одинаковую комнату и выбирают один режим. Онлайн идёт через публичный сервер-ретранслятор (MQTT по WebSocket: EMQX, HiveMQ или Mosquitto — игра сама переключается на доступный). Он работает за любым роутером, свой сервер не нужен.

## Карты
- **Завод «Газ-Ад»** — светлый цех розлива: карусельный разливочный автомат в центре, мост между балконами, конвейеры с едущими бутылками, баки с трубами и вентилями, автоматы с газировкой, вывески «ГАЗ-АД», верхняя галерея по периметру с гейзерами в углах, лучи света из потолочных окон.
- **Площадь фонтана** — летающий остров под чистым небом: фонтан-бутылка колы, колоннада, фонари-бутылки, пальмы, скамейки, террасы с зонтиками. Забор из гигантских банок с перилами-трубочками и медальонами-крышками. С северной стороны — вход на завод «Газ-Ад» с неоновой вывеской и дымящими трубами. Квадратная колоннада с галереей поверху, газовые гейзеры подбрасывают на галерею и на чашу фонтана, монументальные арки по краям. Перепрыгнешь забор — упадёшь с острова.

Карта выбирается в меню. Для онлайна у всех должна быть одна и та же карта.

## Герой «Г-1 Газировщик»
Боевая машина завода в духе машин ULTRAKILL, но со своим дизайном: голова — горлышко бутылки из тёмного стекла с горящим визором и красной кроной-крышкой, угловатый корпус с банкой-ядром в груди, цифровидные ноги с крышками-наколенниками, баллоны CO₂ на спине и энергетические крылья, яркость которых показывает здоровье. Левая рука — сине-бело-красный «кулак» для парирования, правая держит оружие.

- **Анимации:** стойка с дыханием, бег (ноги разворачиваются по направлению движения, корпус — по прицелу), прыжок, подкат, рывок, удар с неба, приземление, удар рукой, отдача от выстрела, падение при смерти.
- **Где видно:** в меню (кнопки показывают каждую анимацию, героя можно повернуть мышью, цвет брони выбирается кружками), у других игроков в онлайне, в виде от третьего лица (**T**), на камере смерти. От первого лица видна своя тень.
- **Оружие в руке:** робо-рука обхватывает рукоять каждой пушки, указательный палец лежит на спуске. Есть доставание, отдача на пружинах, инерция от мыши, покачивание при беге, наклон при стрейфе, проседание при приземлении. У каждой пушки свои движущиеся части: у Шипучки крутится барабан из банок, взводится рычаг, а в тубе видно, сколько осталось крышек; Шейкер передёргивает цевьё и выбрасывает ледяную гильзу; у Ментос-пушки подаётся конфета и качает насос; у Газявы сжимается рычаг сифона, стрелка манометра показывает давление, уровень колы падает, а внутри поднимаются пузырьки. **V** — осмотреть оружие.

## Модели оружия
Пушки — 3D-модели из Blender в папке `models/` (`shipuchka.glb`, `shaker.glb`, `mentos.glb`, `gazyava.glb`). Скрипт, который их строит, — `blender/ultragaz_guns_v3.py`.

## Графика
В меню есть переключатель качества: **Высокая** — тени 2048, свечение и цветокоррекция; **Средняя** — тени попроще; **Низкая** — без теней и свечения, для слабых компьютеров.

## Управление
| Клавиша | Действие |
|---|---|
| WASD, Пробел | Бег и прыжок, у стены — отскок |
| Shift | Рывок с неуязвимостью |
| C | Подкат на земле, удар с неба в воздухе |
| F | Удар и парирование снарядов |
| 1–4, колесо | Шипучка, Шейкер, Ментос-пушка, Газява |
| ЛКМ / ПКМ | Выстрел / альтернативный огонь (у Шипучки — крышка-монетка для рикошета) |
| V | Осмотреть оружие |
| T | Вид от третьего лица |
| Tab, Esc, M | Таблица, пауза, звук |

## Как включить GitHub Pages
Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Сеть
- Каждый игрок раз в ~66 мс отправляет своё состояние в тему комнаты на брокере, остальные его получают.
- Если ни один брокер недоступен, игра пробует прямое P2P через PeerJS.
- В кооперативе врагами управляет один из игроков. Если он выходит, его роль переходит другому.
- Попадания засчитывает стреляющий, поэтому при большом пинге возможны спорные попадания.
